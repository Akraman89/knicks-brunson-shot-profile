# ComfyUI Notes

## Suggested Workflow
1. Find a clear reference photo/video frame of Brunson in a signature pose (step-back mid-range, floater, etc.).
2. Use ControlNet (OpenPose or DWPose) to lock the pose.
3. Generate a clean, well-lit sports photo version.
4. Overlay a translucent zone highlight or heatmap in post (or as a secondary image layer).

## Example Prompt Ideas
- Photorealistic Jalen Brunson mid-range jumper, New York Knicks jersey, hard court, stadium lighting, ball just leaving hand.
- Cinematic low-angle shot of Brunson rising for a step-back, glowing geometric zone marker on the court indicating high-efficiency area.
